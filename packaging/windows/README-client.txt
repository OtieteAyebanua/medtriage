MedTriage - Windows
===================

The MedTriage app for staff computers. It connects to your facility's MedTriage Server over
the Wi-Fi or network; it doesn't store any patient data itself.

Install
  1. Unzip this folder anywhere (for example, your Downloads folder).
  2. Double-click "Install MedTriage.cmd".
     If Windows says "Windows protected your PC", click "More info", then "Run anyway".
  3. A "MedTriage" icon appears on the Desktop and in the Start menu.

Use
  - Double-click "MedTriage". It finds the facility's server and opens MedTriage in its own window.
  - If it can't find the server, it shows a "Connect" screen. Check that this computer is on the
    facility network, or type the address shown on the server computer (e.g. 192.168.1.20).
  - It remembers the server, so next time it opens straight away.

Troubleshooting
  - "No MedTriage Server found": the server computer must be on, with the MedTriage Server
    window open, and on the same network as this computer.
