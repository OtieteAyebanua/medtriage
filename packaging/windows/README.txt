MedTriage AI - Windows
======================

Install
  1. Unzip this folder anywhere (for example, your Downloads folder).
  2. Double-click "Install MedTriage.cmd".
     If Windows says "Windows protected your PC", click "More info", then "Run anyway".
  3. A MedTriage icon appears on your Desktop and in the Start menu.

Use
  - Double-click the MedTriage icon. A black window opens (that's the server) and then the
    MedTriage app window.
  - Keep the black window open while the facility is using MedTriage. Closing it stops MedTriage
    for everyone, including tablets.
  - The black window shows the address for tablets and phones, for example http://192.168.1.20:4000.
    Open that address in the tablet's browser, then use "Add to Home Screen" to get an icon there too.
  - The first time, Windows Firewall may ask about network access. Choose "Allow" on private
    networks, or tablets won't be able to connect.

Your data
  The database and patient photos are stored in %LOCALAPPDATA%\MedTriage.
  Reinstalling or updating MedTriage keeps them. Back this folder up regularly.

Update
  Unzip the new version and run "Install MedTriage.cmd" again.
