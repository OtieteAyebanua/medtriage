MedTriage - macOS
=================

The MedTriage app for staff computers. It connects to your facility's MedTriage Server over
the Wi-Fi or network; it doesn't store any patient data itself.

Which file?
  Apple Silicon Macs (M1, M2, M3, M4 ...):  medtriage-macos-arm64.dmg
  Older Intel Macs:                          medtriage-macos-x64.dmg

Install
  1. Open the .dmg file and drag "MedTriage" onto the Applications folder.
  2. Open "MedTriage" from Applications or Launchpad. To keep it handy, drag it into the Dock.
     The first time, macOS may say it "could not be verified". Click "Done", then open
     System Settings > Privacy & Security, scroll down and click "Open Anyway".

Use
  - Click "MedTriage". It finds the facility's server and opens MedTriage in its own window.
  - If it can't find the server, it shows a "Connect" screen. Check that this Mac is on the
    facility network, or type the address shown on the server computer (e.g. 192.168.1.20).
  - macOS may ask to let MedTriage or Chrome "find devices on your local network".
    Choose "Allow", or it can't reach the server.
  - It remembers the server, so next time it opens straight away.
  - For the app-style window, install Google Chrome or Microsoft Edge; otherwise MedTriage
    opens in Safari.
